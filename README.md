# SipSwift — University Coffee Shop Mobile App

**SipSwift** is a Kotlin-based Android application developed for a university coffee shop. It allows students to browse products, filter the menu, and benefit from a loyalty system based on accumulated stars.

### ⭐ Loyalty Star Counter

<div align="center">
  <img src="https://github.com/ElmahdiAmarjane/KotlinSQLiteCommandAdrink-ESTM/assets/99350940/9eb8c741-db27-4055-820b-2039055e5984" width="300">

The loyalty system tracks the customer's accumulated stars. Once a customer reaches a predefined number of stars, they can unlock a **gift or discount**.

This provides a simple reward mechanism to encourage customer loyalty.

The application provides the customer with access to their loyalty benefits and the available coffee shop services.
